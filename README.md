## Key Features

1. **Mandatory 21+ Age Verification Modal**
   - Compact centered modal dialog (`role="dialog"`, `aria-modal="true"`).
   - Keeps underlying landing page visible as an inert background preview.
   - Synchronous pre-render check preventing any interactive flash.
   - Tab-session persistence via `sessionStorage`.
   - Access-denied state with no bypass for users under 21.

2. **Core Wholesale Product Categories**
   - **Kratom Powder:** Milled *Mitragyna speciosa* leaf powder for bulk wholesale business inquiries.
   - **Kratom Extract:** Concentrated botanical extract products supported by batch-specific documentation.

3. **Quality & Analytical Documentation**
   - Factual summary of independent third-party laboratory reports on file for **Batch SBT4** (Salt-Based Botanical Extract):
     - **Cambium Analytica** (ISO/IEC 17025:2017 #108157) — UPLC-DAD alkaloid determination and USP <467> residual solvents panel.
     - **PharmLabs San Diego** (ISO/IEC 17025:2017 Acc. 85368) — HPLC VWD kratom analysis and GC/FID headspace residual solvents.
   - Respects third-party laboratory reproduction terms with commercial verification inquiry requests. Original PDF files are protected and retained locally.

4. **Wholesale Partnership & Member Portal Separation**
   - Strict separation between public informational pages and the private wholesale member portal (`https://members.purnaturekbulk.com/`).
   - Direct B2B email dispatch for wholesale product specifications, sample documentation, and commercial discussions.

5. **SEO & Social Sharing**
   - Semantic HTML5 structure, Open Graph, Twitter Cards, canonical URL, robots.txt, sitemap.xml, and high-resolution favicon.
   - Lightweight one-click sharing for LinkedIn, Facebook, WhatsApp, and URL copy.

## Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/eksapurnomo/landing-page-purnaturek.git
cd landing-page-purnaturek

# Install dependencies
npm install

# Start development server
npm run dev

# Run production build
npm run build
```
